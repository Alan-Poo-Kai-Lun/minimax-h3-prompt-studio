MiniMax H3 Prompt Studio v0.6.1 使用说明
========================================

一、软件用途
------------
本工具用于在本机调用多模态 AI 模型，把中文或英文创意整理成 MiniMax H3 可用的视频提示词。
软件本身不生成视频，也不连接 ComfyUI；生成好的提示词需要复制到 ComfyUI 的 MiniMax H3 工作流中使用。

二、启动方法
------------
1. 先启动所使用的 AI 后端，例如 Ollama 或 LM Studio，并加载模型。
2. 双击 H3PromptStudio-v0.6.1.exe。
3. 软件会在本机打开：http://127.0.0.1:8765/
4. 第一次使用请打开右上角“设置”，选择 AI 后端并测试连接。

注意：本工具是便携版，不需要安装。关闭程序窗口或结束 H3PromptStudio 进程即可停止服务。

三、AI 后端设置
---------------
支持以下后端：

1. Ollama
   默认地址：http://127.0.0.1:11434
   不需要 API Key。

2. LM Studio
   默认地址：http://127.0.0.1:1234/v1
   需要先在 LM Studio 启动 Local Server。

3. llama.cpp Server
   默认地址：http://127.0.0.1:8080/v1
   需要以 OpenAI 兼容服务模式启动。

4. OpenAI 兼容接口
   填写服务提供方给出的 /v1 地址。
   如果服务要求认证，再填写 API Key；本地服务通常可以留空。

设置步骤：
1. 点击“设置”。
2. 选择 AI 后端。
3. 检查服务地址。
4. 必要时填写 API Key。
5. 点击“测试连接”。
6. 显示连接成功后点击“保存”。
7. 返回主界面选择模型。

建议使用支持图片理解的多模态模型。纯文本模型可以用于 T2VA，但无法可靠分析参考图片。

四、生成模式
------------
T2VA：文本生成视频，不需要参考图片。

I2VA：首帧生成视频。Picture 1 是视频的首帧。

FL2VA：首尾帧生成视频。必须上传两张图片：Picture 1 是首帧，Picture 2 是尾帧。

L2VA：尾帧生成视频。Picture 1 是视频最终画面。

Ref2VA：完整多图参考。可上传人物、产品、场景、服装、道具、LOGO和风格图片。

HYBRID：关键帧、参考媒体和声音混合。至少需要一张被标记为首帧或尾帧的关键帧，并添加普通参考图或参考声音。

五、参考图片与 Picture 编号
---------------------------
1. 图片按照上传顺序自动编号：Picture 1、Picture 2、Picture 3……
2. 每张图片都可以选择用途，并在右侧填写具体说明。
3. 可以查看、复制、替换或删除图片。
4. 删除或更换顺序后，Picture 编号会自动更新。
5. 在“创意内容”或“剧本策划”中输入 @，即可选择参考图片。
6. 选择后会插入 H3 标准格式，例如：<Picture 1>。

示例：
<Picture 1> 是华人女销售，保持脸部、红色长发和黑色制服一致。
<Picture 2> 是手机店内部场景。
<Picture 3> 是品牌 LOGO，只参考其正确图形和文字。

不要自行写错 Picture 数字，否则放入 ComfyUI 后可能引用到错误图片。

六、直接提示词工作流
--------------------
1. 选择生成模式。
2. 在“创意内容”中写场景、人物、动作、对白、风格、镜头和声音要求，并选择“H3 提示词输出语言”。
3. 非 T2VA 模式上传参考图片，并设置每张图片的用途和说明。
4. 选择画面比例、分辨率、分段数量和每段秒数。
5. 在高级设置中填写对白语言、视觉风格、音乐、音效和负面限制。
6. 点击“生成 H3 提示词”。
7. 检查结果后复制全部，或按分段分别复制到 ComfyUI。

七、剧本工作流
--------------
适合广告、剧情短片和多段连续视频。

1. 点击“剧本工作流”。
2. 输入故事、广告要求、人物对白和结局目标。
3. 可输入 @ 引用 Picture。
4. 设置类型、目标观众、语气、剧本输出语言、分段数量及每段时间。
5. 点击“生成分段剧本”。
6. 人工检查并直接修改生成的剧本。
7. 点击“确认剧本并转换为 H3 提示词”。
8. 再点击右侧生成按钮，得到最终的分段 H3 提示词。

八、分段建议
------------
5秒视频：1段 × 5秒。
10秒视频：可使用1段 × 10秒，或2段 × 5秒。
15秒视频：建议3段 × 5秒，生成速度和连续性更容易控制。
20秒视频：建议4段 × 5秒。

分段生成后，需要在剪辑软件中拼接。为了保持连续性，应在每一段中重复人物身份、服装、场景、光线和上一段结束动作。

九、项目、历史与模板
--------------------
保存项目：保存当前设置、参考图、剧本和生成结果。

历史：查看并重新载入之前的生成记录。

模板：可以新增、编辑、使用和删除常用提示词模板。

导出：把项目保存成文件，方便备份或复制到另一台电脑。

导入：载入以前导出的项目文件。

十、常见问题
------------
1. 显示“无法连接 AI 后端”
   检查后端程序是否已启动、端口是否正确，以及防火墙是否阻止本地连接。

2. 模型列表为空
   确认后端已经加载或安装模型，然后点击模型旁边的刷新按钮。

3. 参考图片没有效果
   确认选择的是多模态视觉模型，并正确使用 Ref2VA、I2VA、FL2VA、L2VA 或 HYBRID 模式。

4. 两个人物身份混乱
   给每个人物使用独立 Picture，并在用途说明和每个分段中明确写出人物身份及外观。

5. 输出仍然出现中文
   界面语言与提示词对白语言是不同设置。请在高级设置里明确指定提示词及对白所需语言。

6. 生成很慢
   速度取决于本地模型大小、显卡显存、上下文长度、图片数量和输出长度。可以换较小模型、减少图片、缩短上下文，或把长视频拆成5秒一段。

7. 端口 8765 被占用
   v0.5.5 起会使用独占端口。如果 8765 已被旧版占用，新版会自动寻找 8766–8784 的空闲端口并打开正确页面，不再与旧版随机混用。

十一、隐私说明
--------------
使用 Ollama、LM Studio 或本机 llama.cpp 时，文字和图片只发送到你设置的本地服务地址。
如果填写公网 OpenAI 兼容接口，提示词、参考图片及相关内容会发送给该接口提供方，请自行确认其隐私政策。
API Key 保存在本机浏览器的本地设置中，不要把包含个人配置的数据随意分享给他人。

十三、统一释放显存
------------------
生成结束后，本地 AI 服务可能继续把模型保留在显存中。点击模型选择器旁边的“VRAM”按钮，软件会识别当前 AI 后端并尝试卸载当前模型；也可以在“设置”中开启“生成完成后自动卸载当前后端模型并释放显存”。

目前支持：
1. Ollama：直接卸载当前模型。
2. LM Studio 0.4.0 或以上：调用原生模型卸载接口。
3. llama.cpp Server：需要使用 Router 模式，普通单模型服务器没有统一的动态卸载接口。
4. OpenAI 兼容接口：行业接口没有统一的卸载标准，因此软件会明确提示“不支持”，不会猜测接口或误关服务。

卸载只会释放模型，不会关闭 AI 服务。下一次生成提示词时模型需要重新载入，所以第一次生成可能稍慢。若 LM Studio 显示卸载失败，请确认所选模型对应当前已加载的模型实例；若 llama.cpp 显示卸载失败，请确认已启用 Router 模式。

十四、Picture 引用高亮与预览
----------------------------
在“创意内容”或“剧本策划”中输入 @，选择 Picture 后，参考图栏中对应的 Picture 会以黄色高亮显示，表示它已经被当前内容引用。

正文中的 <Picture 1>、<Picture 2> 会直接显示为黄色高亮标签。把鼠标停在正文标签或下方 Picture 标签上，可以快速查看缩略预览；点击标签可打开大图；点击下方标签右侧的“＋”可再次把该 Picture 编号插入当前光标位置。引用仍以标准文本格式保存和发送给模型，不会改变 ComfyUI 所需编号。

十五、输出语言控制
------------------
“剧本输出语言”只控制剧本工作流生成的剧本正文；“H3 提示词输出语言”控制最终 MiniMax H3 提示词中的说明文字。两项可以分别选择中文、English 或跟随输入。剧本默认中文，H3 提示词默认使用技能规范要求的标准英文。

高级设置中的“对白语言”只控制角色说话所用语言，不会再决定剧本正文或 H3 描述文字的语言。例如可以选择“剧本输出语言：中文”，同时把“对白语言”写成“马来文”。

H3 的固定字段名、Shot 标签、时间码、<Picture N>、<Subject N> 和 <Audio N> 等技术标记始终保留标准英文格式，只有描述正文按所选语言输出。

十六、H3 标准格式
------------------
v0.5.8 起，H3 提示词默认使用“English（H3 标准，推荐）”，并严格按照 h3-prompt-writing 规范生成。

Ref2VA 固定依次输出：subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music。

普通参考图片中的人物、产品、场景或风格必须定义为 <Subject N>，并在定义中注明来源 <Picture N>。summary 以 [reference generation] 等任务类型开头；retention_analysis 使用 fully_preserved 等固定关系；[Shot 1] 不带时间码，后续镜头使用 [Shot N] At MM:SS.mmm, ...。

如果本地模型偶尔返回旧格式，软件会在结果显示前自动规范常见的 Subject、摘要前缀、保留关系及镜头时间写法。中文描述仍可手动选择，但属于非标准翻译模式；要获得最接近技能指南的结果，请使用推荐的标准英文选项。

十七、创意增强 Skill 库
------------------------
点击顶部“技能”或创意内容区的“管理技能”，可以选择、新增、编辑、删除和导入 Skill。最多同时选择 3 个创意增强 Skill，选中的项目会显示在创意内容上方，并随项目保存和导出。

软件内置三种经过 H3 适配的技能：abstract-expression-video-prompter（夸张表情与喜剧演技）、brand-promo-video-generator（真实品牌资产、卖点与 CTA）、paper-collage-explainer-generator（纸张拼贴与触觉定格动画）。它们只增强构思、动作、视觉、节奏和声音；h3-prompt-writing 标准格式始终保持最高优先级。

导入 SKILL.md 后，软件会读取 YAML 头部中的 name、description 以及正文，并先放进编辑器供检查。浏览器安全限制下，SKILL.md 引用的 references、scripts 或其他外部文件不会自动读取，如有必要请把相关创作规则一并粘贴进 Skill 正文。

为避免自定义文件破坏输出，软件不会执行 Skill 中的工具调用、联网、文件访问、审批流程或外部媒体生成指令，也不会允许其覆盖 H3 字段、模式、分段、语言和 Picture 编号规则。

十八、参考图拖拽与剪贴板
--------------------------
每张参考图卡片都有“⠿ 拖拽排序”按钮。按住按钮拖到另一张 Picture 的上半部或下半部，即可插入到该 Picture 前面或后面。黄色横线会显示即将插入的位置。重排完成后，软件会自动更新创意内容、剧本和当前生成结果里的 Picture 编号。

点击参考图卡片的空白位置或缩略图，可以把它选为“剪贴板目标”。目标卡片会出现低调高亮和“剪贴板目标”标记：
1. Ctrl+C：复制当前选中的 Picture 图片。
2. 选中另一张卡片后 Ctrl+V：用复制或系统剪贴板中的图片替换目标 Picture，并保留目标原有用途和说明。
3. 按 Esc 取消选择后 Ctrl+V：把图片新增为最后一个 Picture。
4. Windows 截图、网页复制的图片和其他系统剪贴板图片也可以直接 Ctrl+V 添加或替换。

在输入框中进行普通文字复制粘贴时，软件不会抢占 Ctrl+C / Ctrl+V。
